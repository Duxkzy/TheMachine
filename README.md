# The Machine

An intelligent voice assistant featuring system tool integration, desktop control, computer vision, and web search capabilities.

## Setup & Mounting Instructions

The fastest and recommended way to initialize the project structure—including the creation of necessary configuration files for your API keys—is by running the setup script using the **Visual Studio Code** debugger.

Follow these steps:

1. Open the project folder in Visual Studio Code.
2. Open the `setup.py` file.
3. Press **F5** on your keyboard.
4. From the top dropdown menu, select **Python File** (under "Python Debugger").

The `setup.py` script will automatically generate the `config/api_keys.json` file along with any missing directories. Once you insert your Gemini API key into the generated JSON file or on the visual first boot, you can launch `main.py` to start the assistant.
